# Web Timer

一个现代化的网页版正计时器，采用 Glassmorphism 玻璃拟态设计风格，支持计次、暂停、重置等功能。

## 功能

- 正计时，从 0 开始累加，精确到百分秒
- **计次功能**：记录中途时间，自动标记最快 / 最慢分段
- 显示格式：时:分:秒.百分秒
- 支持快捷键：
  - `空格键`：开始 / 暂停
  - `R`：重置
  - `L`：记录计次
- 动态页面标题，实时显示当前计时
- Glassmorphism 玻璃拟态 UI，渐变背景 + 浮动光球动画
- 响应式设计，适配手机和电脑
- PWA 支持，可安装为桌面 / 手机应用

## 使用

直接在浏览器中打开 `index.html` 文件即可。
